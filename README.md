# 🚚 GapTrack — Coverage Gap Detection System

نظام ذكي لسد الفجوات في تتبع الشحنات والتنبؤ بمناطق ضعف التغطية.

## 📌 عن المشروع (About)

تعتمد أنظمة تتبع الشحنات التقليدية على عرض الموقع اللحظي فقط، ولكنها تفشل في التعامل بذكاء مع لحظات انقطاع الإشارة (Signal Dropouts) عند مرور المركبة بمناطق جغرافية ضعيفة التغطية أو أثناء النقل الطويل.

يقدم GapTrack حلاً هندسياً بتمييز نوع الانقطاع تلقائياً (هل هو دخول منطقة ضعف تغطية معروفة أم انقطاع غير طبيعي يستدعي المتابعة الفورية؟)، مع إرسال تنبيهات استباقية وتوفير تقارير تحليلية لخريطة الحرارة (Heatmap) لدعم قرارات تحسين البنية التحتية.

## ✨ المميزات الرئيسية (Key Features)

- 🗺️ **تتبع لحظي ومحاكاة حية:** عرض مسار الشحنة على خريطة تفاعلية باستخدام Leaflet.js مع إمكانية تشغيل محاكاة الحركة خطوة بخطوة.
- 🧠 **كشف ذكي للانقطاعات:** التمييز الآلي بين:
  - منطقة ضعف تغطية معروفة (Gap Zone): منطقة محددة مسبقاً بالنظام مع تقدير وقت عودة الإشارة.
  - انقطاع غير طبيعي (Abnormal Gap): انقطاع مفاجئ خارج المناطق المعروفة يتجاوز المدة الطبيعية.
- 🔮 **التنبؤ الاستباقي:** احتساب المسافة نحو أقرب منطقة ضعف تغطية معروفة وتنبيه النظام قبل دخولها.
- 📊 **التقرير التحليلي والخريطة الحرارية:** تجميع سجلات الانقطاع وتجسيدها بـ Heatmap لتحديد أكثر المناطق تضرراً.
- ⚡ **محاكاة الضغط (Stress Testing):** إمكانية توليد شحنات ومسارات عشوائية متعددة لتقييم أداء النظام تحت الضغط.
- 🏅 **شارات الإنجاز:** تصنيف تلقائي لكل رحلة (سليمة / مرت بمنطقة ضعف تغطية / عالية الخطورة).
- 🎨 **واجهة داكنة عصرية:** تصميم Dark Mode متكامل بهوية بصرية موحدة عبر كل صفحات النظام.

## 🛠️ المكدس التقني (Tech Stack)

- **Backend:** PHP (OOP / Procedural)
- **Database:** MySQL / MariaDB
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Mapping & Visualization:** Leaflet.js, Leaflet.heat, Stadia Maps Tiles
- **Environment:** Apache / XAMPP

## 🚀 التشغيل المحلي (Local Setup)

1. حمّل المشروع وضعه داخل مجلد `htdocs` الخاص بـ XAMPP:

C:\xampp\htdocs\GapTrack


2. شغّل **Apache** و **MySQL** من لوحة تحكم XAMPP.

3. افتح phpMyAdmin عبر:

http://localhost/phpmyadmin


4. أنشئ قاعدة بيانات جديدة باسم `gaptrack`، ثم استورد ملف `schema.sql` الموجود بالمشروع (يحتوي على الجداول الأربعة + بيانات تجريبية جاهزة).

5. تأكد أن بيانات الاتصال بملف `config/db.php` مطابقة لإعداداتك المحلية (الاسم، المستخدم، كلمة المرور، المنفذ).

6. افتح المتصفح على:

http://localhost/GapTrack/index.php
